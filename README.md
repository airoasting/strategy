# 전략 프레임워크 갤러리 + 추천 스킬

맥킨지·베인·BCG 현장에서 가장 많이 쓰이는 **30개 전략 사고 도구**를 6개 카테고리로 정리한 프로젝트.

- **갤러리** (`index.html`) — 카드 형태로 30개 프레임워크를 탐색하는 정적 웹사이트
- **추천 스킬** (`skill/`) — 자연어로 상황을 설명하면 최적 프레임워크를 골라주는 Claude Code 스킬

---

## 갤러리 실행

```bash
npx http-server . -p 8000
# 브라우저에서 http://localhost:8000 열기
```

또는:

```bash
python3 -m http.server 8000
```

### 주요 기능

- 30개 프레임워크 카드 갤러리 (6개 카테고리)
- 카테고리 필터 칩 — 클릭 시 해당 섹션으로 스크롤, 스크롤 스파이 연동
- 상단 검색창 실시간 필터링
- 카드 클릭 → 모달 상세 (개요·언제·구성·절차·예시·한계·관련 도구)
- 라이트 / 다크 모드 전환 (localStorage 저장)
- 관련 도구 클릭 시 모달 즉시 전환

### 배포

루트 폴더 그대로 정적 호스팅에 올리면 됩니다 (GitHub Pages, Vercel, Netlify 등).

---

## 추천 스킬 설치

```bash
# 심볼릭 링크 (권장)
ln -s "$(pwd)/skill" ~/.claude/skills/strategy-framework

# 또는 복사
cp -r skill ~/.claude/skills/strategy-framework
```

### 사용 예시

```
사용자: 신사업 검토 중인데 어떤 프레임워크부터 써야 할지 모르겠어
스킬:   추천: 3C 분석 (#4) — 이유 + 적용 단계 + 한계 + 대안

사용자: 팀 간 책임이 모호해서 협업이 자꾸 막혀
스킬:   추천: RACI 차트 (#16) — ...

사용자: 스타트업인데 빠르게 사업 모델 검증해야 해
스킬:   추천: Lean Canvas (#26) — ...
```

트리거: "프레임워크 추천", "전략 도구 골라줘", "사업 진단 어떻게", `/strategy-framework`
