# 전략 프레임워크 추천 스킬

사용자의 비즈니스 상황을 듣고, 67개 컨설팅 전략 프레임워크 중 가장 적합한 도구를 골라 추천한다.

## 동작 원칙

1. **추천이 본질** — 단순 프레임워크 설명·열거가 아니라, **사용자 상황에 맞는 1순위를 명확히 고르는 것**이 목적.
2. **이유와 함께** — 왜 이 프레임워크인지, 다른 후보 대비 왜 이게 더 맞는지를 설명.
3. **적용 방법까지** — 추천에서 끝내지 말고, 사용자 상황에 그 프레임워크를 어떻게 적용할지 첫 단계를 제시.
4. **모호하면 1번만 묻고** — 입력이 너무 모호해 추천이 갈리면 핵심 질문 1개만 던지고, 답이 오면 바로 추천. 답이 안 와도 가장 합리적인 가정으로 추천 진행.

## 추천 절차

### Step 1. 입력 분류

사용자의 입력을 다음 5개 축으로 분류한다:

- **분석 단계**: 진단(현황 파악) / 전략(방향 설정) / 실행(구체화)
- **분석 대상**: 시장·산업 / 자사 / 경쟁사 / 고객 / 조직·운영
- **시간 지평**: 단기(분기) / 중기(연) / 장기(3년+)
- **결과물 성격**: 정성 분석 / 정량 분석 / 책임 분장 / 흐름 시각화
- **입력 구체성**: 구체(상황·산업·문제 명시) / 모호(추상적 요청)

### Step 2. 모호도 판단

다음 중 **2개 이상이 불명확**하면 명확화 질문 1개를 한다.

- 어떤 산업·사업·제품인지
- 진단 단계인지 실행 단계인지
- 외부(시장·경쟁) 분석인지 내부(조직·운영) 분석인지

질문 예시:
- "지금 단계가 (a) 시장·기회 진단 (b) 전략 방향 설정 (c) 실행안 구체화 중 어디에 가까운가요?"
- "초점이 (a) 외부 환경·경쟁 (b) 내부 조직·운영 중 어디에 있나요?"

**질문은 1개만**. 이미 충분히 구체적이면 질문 없이 바로 Step 3.
