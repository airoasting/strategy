# 결정 트리 — 자연어 입력에서 프레임워크로

사용자의 입력을 다음 트리로 풀어 가장 먼저 추천할 1순위를 결정한다.

## 0. 명확화 우선

다음 중 **2개 이상**이 모호하면 1개 질문을 먼저 던진다:
- 산업·사업 도메인이 빠짐
- 외부 환경(시장·경쟁·고객) vs 내부(조직·운영) 구분 불명
- 진단(현황 파악) vs 전략(방향) vs 실행(구체화) 단계 불명

질문 예: "지금 단계가 (a) 시장·기회 진단 (b) 전략 방향 (c) 실행 구체화 중 어디인가요?"

질문 1개 후, 답이 와도 안 와도 Step 1로.

## 1. 분기 1 — 어떤 영역의 문제인가

### A. 문제 해결·사고 도구가 필요한 경우
- "문제를 구조적으로 쪼개야", "이슈를 MECE하게 정리", "논리 구조화" → **#19 이슈 트리 / MECE**
- "미래 불확실성 대비", "시나리오별 전략", "장기 전략 기획" → **#22 시나리오 플래닝**
- "보고서 메시지 정리", "결론 먼저 말하는 구조", "경영진 커뮤니케이션" → **#28 피라미드 원칙**
- "사용자 공감에서 출발", "혁신적 해법 탐색", "서비스 재설계" → **#30 디자인 씽킹**

### B. 시장 / 경쟁 / 환경 문제
- "신사업 시장 분석 첫 단계", "큰 그림", "어떤 시장인가" → **#4 3C 분석**
- "강점·약점 정리", "워크숍 합의", "경영진 보고용" → **#5 SWOT** (깊이 필요하면 3C·5Forces 추천)
- "산업 진입할까", "이 산업 매력도", "장기 수익성" → **#6 5 Forces**
- "거시환경 변화", "정책·규제 영향", "장기 외부 변수" → **#7 PEST(EL)**
- "사업 포트폴리오 정리", "어디에 투자", "성장성·점유율" → **#17 BCG 매트릭스**
- "성장 방향 옵션", "신시장 vs 기존 시장", "다각화 전략" → **#18 Ansoff 매트릭스**
- "다사업부 포트폴리오 평가", "복합 기준 사업 우선순위" → **#21 GE-9Box 매트릭스**
- "경쟁 없는 새 시장 창출", "가치 혁신", "차별화·저비용 동시" → **#24 블루오션 전략**

### C. 마케팅 문제
- "타깃 누구로", "포지셔닝", "세분화" → **#8 STP 분석**
- "신제품 출시 마케팅", "가격·유통·프로모션", "실행안" → **#9 4P**
- "고객 경험 개선", "전환·이탈 분석", "UX·서비스 흐름" → **#10 Customer Journey Map**
- "고객이 진짜 원하는 것", "해결해야 할 일 정의", "니즈 발굴" → **#25 JTBD**
- "기능 우선순위", "고객 만족도 분류", "Must-have vs Nice-to-have" → **#27 Kano 모델**
- "경쟁자 대비 포지셔닝 시각화", "어디에 있을지 결정" → **#29 포지셔닝 맵**

### D. 비즈니스 모델·수익 구조 문제
- "신사업 구조 시각화", "사업 모델 설계" → **#1 BMC**
- "이익이 안 난다", "수익성 분석", "원가 vs 가격" → **#2 이익 방정식**
- "수익화 방식", "구독·광고 어떤 모델", "플랫폼 수익화" → **#3 수익 모델**
- "스타트업 빠른 검증", "가설 중심 사업 계획" → **#26 Lean Canvas**

### E. 조직 / 내부역량 문제
- "경쟁우위 어디서", "원가 vs 차별화", "핵심 역량" → **#11 가치 사슬**
- "전략은 좋은데 실행이 안 됨", "M&A 후 통합", "조직 정렬" → **#12 7S**
- "디지털·데이터·보안 역량 진단", "DT 성숙도" → **#13 성숙도 평가**
- "전략 목표를 KPI로 연결", "재무·고객·프로세스·학습 균형" → **#20 BSC**
- "목표 설정·분기 실행", "팀 간 목표 정렬", "OKR 도입" → **#23 OKR**

### F. 프로세스 / 운영 문제
- "리드타임 단축", "병목 진단", "운영 효율화" → **#14 프로세스 분해**
- "프로세스 정의 첫 단계", "이해관계자 합의", "큰 그림 흐름" → **#15 SIPOC**
- "책임 모호", "협업 깨짐", "누가 결정", "조직 개편 후 R&R" → **#16 RACI**

## 4. 자주 헷갈리는 경계

- **#1 BMC vs #26 Lean Canvas** — 검증된 사업 구조 설계면 #1, 스타트업 가설 검증이면 #26.
- **#1 BMC vs #3 수익 모델** — 사업 전체 그림이면 #1, 돈을 어떻게 받는지에 초점이면 #3.
- **#2 이익 방정식 vs #11 가치 사슬** — 이익 변수 정량 분석이면 #2, 활동별 가치·비용 구조면 #11.
- **#4 3C vs #6 5 Forces** — 자사·고객·경쟁의 큰 그림이면 #4, 산업 매력도·구조면 #6.
- **#5 SWOT vs #4 3C** — 경영진 보고·합의용이면 #5, 분석의 깊이를 원하면 #4.
- **#17 BCG vs #21 GE-9Box** — 단순 성장성·점유율 분류면 #17, 복합 기준 심층 평가면 #21.
- **#9 4P vs #8 STP** — 타깃·포지셔닝(전략)이면 #8, 실행 변수(가격·유통·프로모션)면 #9.
- **#25 JTBD vs #30 디자인 씽킹** — 니즈 정의에 초점이면 #25, 공감→프로토타입 전 과정이면 #30.
- **#20 BSC vs #23 OKR** — 장기 전략 KPI 균형이면 #20, 분기 단위 목표 실행 정렬이면 #23.
- **#11 가치 사슬 vs #14 프로세스 분해** — 경쟁우위 원천 진단이면 #11, 운영 효율화면 #14.
- **#12 7S vs #16 RACI** — 조직 전체 정렬이면 #12, 활동별 책임 분장이면 #16.
- **#14 프로세스 분해 vs #15 SIPOC** — 단계별 시간·병목 분석이면 #14, 큰 그림 + 이해관계자면 #15.
- **#10 CJM vs #14 프로세스 분해** — 고객 관점 경험이면 #10, 내부 운영 흐름이면 #14.
