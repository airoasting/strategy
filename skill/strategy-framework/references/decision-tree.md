# 결정 트리 — 자연어 입력에서 프레임워크로

사용자의 입력을 다음 트리로 풀어 가장 먼저 추천할 1순위를 결정한다.

## 0. 명확화 우선

다음 중 **2개 이상**이 모호하면 1개 질문을 먼저 던진다:
- 산업·사업 도메인이 빠짐
- 외부 환경(시장·경쟁·고객) vs 내부(조직·운영) 구분 불명
- 진단(현황 파악) vs 전략(방향) vs 실행(구체화) 단계 불명

질문 예: "지금 단계가 (a) 시장·기회 진단 (b) 전략 방향 (c) 실행 구체화 중 어디인가요?"

질문 1개 후, 답이 와도 안 와도 Step 1로.

## 1. 분기 1 — 어떤 영역의 문제인가

### A. 사업 모델 / 수익성 문제
- "신사업 어떻게 설계", "사업 모델", "구조 시각화" → **#1 BMC**
- "이익이 안 난다", "수익성 분석", "원가 vs 가격" → **#2 이익 방정식**
- "수익화 방식", "구독·광고 어떤 모델", "플랫폼 수익화" → **#3 수익 모델**

### B. 시장 / 경쟁 / 환경 문제
- "신사업 시장 분석 첫 단계", "큰 그림", "어떤 시장인가" → **#4 3C**
- "강점·약점 정리", "워크숍 합의", "경영진 보고용" → **#5 SWOT** (단, 깊이 필요하면 3C·5 Forces 추천)
- "산업 진입할까", "이 산업 매력도", "장기 수익성" → **#6 5 Forces**
- "거시환경 변화", "정책·규제 영향", "장기 외부 변수" → **#7 PEST(EL)**

### C. 마케팅 문제
- "타깃 누구로", "포지셔닝", "세분화" → **#9 STP**
- "신제품 출시 마케팅", "가격·유통·프로모션", "실행안" → **#8 4P**
- "고객 경험 개선", "전환·이탈 분석", "UX·서비스 흐름" → **#10 Customer Journey Map**

### D. 조직 / 내부역량 문제
- "경쟁우위 어디서", "원가 vs 차별화", "핵심 역량" → **#11 가치 사슬**
- "전략은 좋은데 실행이 안 됨", "M&A 후 통합", "조직 정렬" → **#12 7S**
- "디지털·데이터·보안 역량 진단", "DT 성숙도" → **#13 성숙도 평가**

### E. 프로세스 / 운영 문제
- "리드타임 단축", "병목 진단", "운영 효율화" → **#14 프로세스 분해**
- "프로세스 정의 첫 단계", "이해관계자 합의", "큰 그림 흐름" → **#15 SIPOC**
- "책임 모호", "협업 깨짐", "누가 결정", "조직 개편 후 R&R" → **#16 RACI**

## 4. 자주 헷갈리는 경계

- **#1 BMC vs #3 수익 모델** — 사업 전체 그림이면 #1, 돈을 어떻게 받는지에 초점이면 #3.
- **#2 이익 방정식 vs #11 가치 사슬** — 이익 변수 정량 분석이면 #2, 활동별 가치·비용 구조면 #11.
- **#4 3C vs #6 5 Forces** — 자사·고객·경쟁의 큰 그림이면 #4, 산업의 매력도·구조면 #6.
- **#5 SWOT vs #4 3C** — 경영진 보고·합의용이면 #5, 분석의 깊이를 원하면 #4.
- **#8 4P vs #9 STP** — 타깃·포지셔닝(전략)이면 #9, 실행 변수(가격·유통·프로모션)면 #8.
- **#11 가치 사슬 vs #14 프로세스 분해** — 경쟁우위 원천 진단이면 #11, 운영 효율화면 #14.
- **#12 7S vs #16 RACI** — 조직 전체 정렬이면 #12, 활동별 책임 분장이면 #16.
- **#14 프로세스 분해 vs #15 SIPOC** — 단계별 시간·병목 분석이면 #14, 큰 그림 + 이해관계자면 #15.
- **#10 CJM vs #14 프로세스 분해** — 고객 관점 경험이면 #10, 내부 운영 흐름이면 #14.
