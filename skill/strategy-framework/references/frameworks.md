# 16개 전략 프레임워크 인벤토리

추천 응답을 만들 때 이 파일의 정보를 정확히 사용한다. 카테고리·이름·구성·적용 단계·예시·한계가 모두 명세되어 있다.

---

## 카테고리 1. 비즈니스 모델·수익 구조 분석

### #1. 비즈니스 모델 캔버스 (Business Model Canvas)
- 사용 빈도 ★★★★★ / 효과성 ★★★★☆
- **한 줄**: 사업 모델을 9개 블록으로 한 장에 시각화하는 표준 도구
- **개요**: 오스터왈더(Osterwalder)의 9블록 캔버스. 고객·가치·채널·수익·자원·비용을 한 장에 펼쳐 사업 전체 그림과 블록 간 정합성을 한눈에 점검.
- **언제**: 신규 사업 초기 모델링 / 사업 한 장 설명 / 팀 그림 공유 / 피벗·리뉴얼 직전 모델 진단.
- **구성**: Customer Segments, Value Propositions, Channels, Customer Relationships, Revenue Streams, Key Resources, Key Activities, Key Partnerships, Cost Structure.
- **절차**: 고객 → 가치 → 채널·관계 → 수익 → 자원·활동·파트너 → 비용 → 정합성 점검.
- **예시**: 토스 — 고객(금융 사용자) / 가치(쉬운 송금·통합) / 채널(앱) / 수익(수수료·광고).
- **한계**: 깊이 부족, 경쟁·환경 분석 약함, 캔버스 채우기에 만족하기 쉬움.
- **관련**: #3 수익 모델, #11 가치 사슬, #14 프로세스 분해.

### #2. 이익 방정식 (Profit Equation)
- 사용 빈도 ★★★★★ / 효과성 ★★★★★
- **한 줄**: 수익성 개선을 위한 전략적 구조 이해에 탁월
- **개요**: 이익 = (P − V) × Q − F. 4변수로 분해해 어떤 레버가 이익에 가장 큰 영향을 주는지 정량 진단.
- **언제**: 이익 하락 원인 진단 / 가격 의사결정 시뮬레이션 / 원가 vs 매출 우선순위 / 사업 단위 비교.
- **구성**: P(가격), V(변동비), Q(수량), F(고정비), 공헌이익(P-V).
- **절차**: 4변수 수치 → 손익분기 → 1% 변화 민감도 → 핵심 레버 식별 → 옵션 도출 → 시나리오.
- **예시**: 스타벅스 가격 5% 인상의 P/Q/공헌이익/F 영향 정량화.
- **한계**: 장기 효과(브랜드·충성도) 반영 어려움, 변수 추정 부정확하면 결과 왜곡, 다품종 단순화 까다로움.
- **관련**: #1 BMC, #3 수익 모델, #14 프로세스 분해.

### #3. 비즈니스 모델 / 수익 모델 (Revenue Model)
- 사용 빈도 ★★★☆☆ / 효과성 ★★★★☆
- **한 줄**: 플랫폼·디지털 사업 수익 구조 설계에 적합
- **개요**: 누구에게(payer)·무엇으로·얼마나·어떻게 받는가를 구체화. 구독·거래·광고·라이선스·프리미엄 등.
- **언제**: 신규 디지털·플랫폼 수익화 / 수익화 다각화 / 프리·유료 전환 / 양면 시장 가격.
- **구성**: 수익원 유형 / Payer / Pricing 단위 / 결제 주기 / 수익화 시점.
- **절차**: 가치 명세 → payer 식별 → 수익원 후보 → 단가·전환·LTV → CAC와 단위경제성 → 1차 모델.
- **예시**: Notion — 개인 무료 / 팀 시트당 / 엔터프라이즈 보안.
- **한계**: 단독 사용 시 시장 관점 약함, 가설은 빠른 검증 필요, B2B 복잡 거래 단순화 어려움.
- **관련**: #1 BMC, #2 이익 방정식, #9 STP.

## 카테고리 2. 시장·경쟁 분석

### #4. 3C 분석 (3C: Customer · Competitor · Company)
- 사용 빈도 ★★★★★ / 효과성 ★★★★☆
- **한 줄**: 가장 범용적인 시장 구조 분석 도구
- **개요**: 시장 진단의 첫 도구. 고객·경쟁자·자사 3축으로 큰 그림.
- **언제**: 신사업 초기 / 포지셔닝 재점검 / 빠른 구조화 / 더 깊은 분석 전 큰 그림.
- **구성**: Customer(시장·세그먼트·니즈), Competitor(점유·강점·약점), Company(자원·역량·포지션).
- **절차**: Customer → Competitor → Company → 교차점 → KSF → 전략 방향.
- **예시**: 쿠팡 초기 — 고객(빠른 배송 원함) × 경쟁(11번가·G마켓 배송 약함) × 자사(IT·자본) → '로켓배송' KSF.
- **한계**: 깊이 한계, 거시환경 빠짐, 시간축 약함.
- **관련**: #5 SWOT, #6 5 Forces, #7 PEST.

### #5. SWOT 분석
- 사용 빈도 ★★★★★ / 효과성 ★★☆☆☆
- **한 줄**: 널리 쓰이나 깊이 있는 분석에는 한계
- **개요**: S/W/O/T 4분면. 단독 사용 시 평면적, SO/WO/ST/WT 4교차 전략까지 가야 가치.
- **언제**: 워크숍 합의 / 다른 분석 결과 종합 / 임원에게 큰 그림 (메인 도구로는 부적절).
- **구성**: S, W, O, T + SO/WO/ST/WT 4교차 전략.
- **절차**: 내부(S/W) → 외부(O/T) → 4교차 전략 도출.
- **예시**: 넷플릭스 한국 — S(글로벌 콘텐츠·기술) × O(국내 OTT 미성숙) → SO: 한국 오리지널 대규모 투자.
- **한계**: 내부/외부 구분 모호, 우선순위 빠짐, 정태적, 단독 깊이 부족.
- **관련**: #4 3C, #6 5 Forces, #7 PEST.

### #6. 5 Forces 분석 (Porter's Five Forces)
- 사용 빈도 ★★★★☆ / 효과성 ★★★★★
- **한 줄**: 산업 진입 전략과 구조 분석에 강력
- **개요**: 산업의 장기 매력도(=수익성)를 결정하는 5가지 힘.
- **언제**: 신규 산업 진입 / 산업 매력도 재평가 / 구조적 수익성 원인 분석 / M&A 산업 평가.
- **구성**: 신규 진입 위협 / 공급자 협상력 / 구매자 협상력 / 대체재 위협 / 기존 경쟁 강도.
- **절차**: 산업 정의 → 5힘 결정요인 → 강도 평가 → 매력도 종합 → 자사 포지션 → 전략.
- **예시**: 한국 항공 — 진입(低)·공급자(高)·구매자(高)·대체재(中)·경쟁(高) → 매력도 낮음. LCC 차별화 또는 프리미엄 집중.
- **한계**: 정태적, 보완 관계 빠짐, 산업 정의 모호하면 흔들림, 디지털 플랫폼 적용 시 추가 도구 필요.
- **관련**: #4 3C, #7 PEST, #11 가치 사슬.

### #7. PEST(EL) 분석
- 사용 빈도 ★★★☆☆ / 효과성 ★★★☆☆
- **한 줄**: 거시환경 변화 파악용, 보조 도구로 적합
- **개요**: P·E·S·T (+E·L) — 외부 거시환경 스캔. 5 Forces·SWOT의 입력.
- **언제**: 장기 전략 외부 점검 / 신규 국가 진출 / 규제 큰 산업(금융·의료·에너지) / 다른 프레임 입력.
- **구성**: Political / Economic / Social / Technological / Environmental / Legal.
- **절차**: 범위 → 영역별 변화요인 → 영향력·시간 평가 → 핵심 3~5개로 압축 → 자사 함의 → 다른 프레임에 연결.
- **예시**: 전기차 PESTEL — P(탄소중립)·E(원자재)·S(친환경 소비)·T(배터리)·E(환경규제)·L(보조금법). 핵심: 보조금 + 배터리.
- **한계**: 단순 나열로 끝나면 무용, 시차 큼, 상호작용 약함, 보조 도구로 활용해야 효과적.
- **관련**: #4 3C, #5 SWOT, #6 5 Forces.

## 카테고리 3. 마케팅 전략

### #8. 4P (마케팅 믹스)
- 사용 빈도 ★★★★★ / 효과성 ★★★★☆
- **한 줄**: 실행 중심 마케팅 전략 수립의 기본 도구
- **개요**: Product·Price·Place·Promotion. STP 다음, 실행 변수 결정.
- **언제**: 신제품 출시 / 마케팅 재정비 / STP 다음 단계 / ROI 점검·재배분.
- **구성**: Product / Price / Place / Promotion.
- **절차**: 표적 고객 → Product → Price → Place → Promotion → 4P 일관성 점검 → 자원·KPI.
- **예시**: 다이슨 — Product(고가·고성능)·Price(프리미엄)·Place(백화점·자사몰)·Promotion(체험·기술 시연). 4P 모두 '프리미엄 기술 가전'.
- **한계**: 고객 관점 약함(4C 보완), 디지털 채널 복잡성 한계, 내부 자원 변수 빠짐.
- **관련**: #9 STP, #10 CJM, #14 프로세스 분해.

### #9. STP 분석 (Segmentation · Targeting · Positioning)
- 사용 빈도 ★★★★☆ / 효과성 ★★★★★
- **한 줄**: 타깃 정의 및 브랜드 포지셔닝 전략의 핵심
- **개요**: 시장 세분화 → 표적 시장 선정 → 포지셔닝. 마케팅 전략의 출발점.
- **언제**: 신제품·신규 브랜드 / 리포지셔닝 / 자원 집중 결정 / 포화 시장 차별화.
- **구성**: Segmentation, Targeting, Positioning, 포지셔닝 맵.
- **절차**: 시장 정의 → 세분화 변수 → 세그먼트 매력도 → 표적 선정 → 포지셔닝 컨셉 → 포지셔닝 맵 → 4P 구현.
- **예시**: 에어비앤비 — 세분화(여행 숙박)→타깃(저렴+현지 경험 밀레니얼)→포지셔닝('어디서나 살아보는 경험').
- **한계**: 변수 선택이 잘못되면 흔들림, 인지 측정 어려움, 디지털 환경에서 동적 세그먼트 한계.
- **관련**: #8 4P, #10 CJM, #4 3C.

### #10. Customer Journey Map (고객 여정 지도)
- 사용 빈도 ★★★☆☆ / 효과성 ★★★★☆
- **한 줄**: 디지털 환경에서 고객경험 개선에 유용
- **개요**: 인지→고려→구매→사용→재구매 여정을 단계별로 매핑. Action·Thinking·Feeling·Touchpoints·Pain Points.
- **언제**: CX 개선 / 옴니채널 설계 / 전환·이탈 진단 / 디지털 서비스 UX 설계.
- **구성**: Persona, 단계, Action, Thinking, Feeling, Touchpoints, Pain Points / Opportunities.
- **절차**: 페르소나 → 단계 → 행동·생각·감정 인터뷰 → 터치포인트 → 페인포인트·MoT → 개선 기회 → To-Be.
- **예시**: 스타벅스 '대기' 단계 페인포인트 → 사이렌 오더로 단계 자체 재설계.
- **한계**: 데이터 없이 가정만으로는 픽션, B2B 복잡 여정 한계, 정량 데이터 결합 필요.
- **관련**: #9 STP, #14 프로세스 분해, #15 SIPOC.

## 카테고리 4. 조직·내부역량 분석

### #11. 가치 사슬 분석 (Value Chain)
- 사용 빈도 ★★★★★ / 효과성 ★★★★★
- **한 줄**: 장기 경쟁우위와 핵심 역량 정의에 매우 효과적
- **개요**: 본원적 활동(물류·운영·마케팅·서비스) + 지원 활동(인프라·HR·기술·조달). 가치·비용 원천 진단.
- **언제**: 장기 경쟁우위 / 원가 vs 차별화 결정 / 아웃소싱·내재화 / 핵심 역량 식별.
- **구성**: 본원적 5활동 + 지원 4활동 + Margin.
- **절차**: 사슬 정의 → 활동별 비용 → 가치 기여 → 경쟁사 비교 → 차별화·원가 원천 → 약점 개선·외주 → 자원 집중.
- **예시**: 이케아 — 디자인·조달·운영(평면 패키지)·물류(자가)·매장 통합 → '저가 + 디자인'의 원천이 사슬 곳곳.
- **한계**: 서비스·디지털 사업에 어색, 활동별 비용 데이터 어려움, 외부 사슬과 연결까지 봐야.
- **관련**: #6 5 Forces, #12 7S, #14 프로세스 분해.

### #12. 맥킨지 7S 분석
- 사용 빈도 ★★★☆☆ / 효과성 ★★★★☆
- **한 줄**: 조직 정렬성과 전략 실행 진단에 유용
- **개요**: Hard 3S(Strategy·Structure·System) + Soft 4S(Shared Values·Style·Staff·Skills). 실행 정렬 진단.
- **언제**: 전략은 좋은데 실행이 안 될 때 / M&A 후 PMI / 변화 관리·조직 개편 / 조직·문화 진단.
- **구성**: Strategy, Structure, System, Shared Values(중심), Style, Staff, Skills.
- **절차**: 7S 진단 → Strategy 명확화 → 정렬 평가 → 갭 식별 → To-Be 7S → 전환 로드맵.
- **예시**: GE 잭 웰치 — Strategy(글로벌 1·2위)·Structure·System·Style·Staff·Skills·Values 모두 정렬.
- **한계**: 정성적, Soft S 측정·변화 어려움, 외부 환경 반영 약함.
- **관련**: #11 가치 사슬, #13 성숙도, #16 RACI.

### #13. 역량 성숙도 평가 (CMMI / Capability Maturity)
- 사용 빈도 ★★☆☆☆ / 효과성 ★★★★☆
- **한 줄**: IT·운영 영역에서 실행 역량 수준 진단에 적합
- **개요**: 5단계(Initial→Managed→Defined→Quantitatively Managed→Optimizing). 현재·목표·갭.
- **언제**: 디지털 전환·DT 진단 / 데이터·AI 역량 / 보안 성숙도 / 프로세스 표준화.
- **구성**: L1~L5 5단계 모델.
- **절차**: 영역 정의 → 평가 rubric → 현재 레벨 → 시각화 → To-Be → 갭 → 단계별 로드맵.
- **예시**: 제조사 데이터 — 수집 L3 / 거버넌스 L1 / 분석 L2 / AI L1 → 거버넌스를 L3까지 1년 우선 과제.
- **한계**: 평가자 주관, 모든 영역 최고 레벨 비효율, 모델이 산업·맥락에 맞아야.
- **관련**: #12 7S, #14 프로세스 분해, #16 RACI.

## 카테고리 5. 프로세스 분석

### #14. 프로세스 분해 (Process Decomposition)
- 사용 빈도 ★★★★★ / 효과성 ★★★★☆
- **한 줄**: 서비스 흐름·업무 병목 구조화의 기본 툴
- **개요**: 복잡한 업무를 활동 단위로 쪼개고 시간·자원·산출물·이슈를 매핑.
