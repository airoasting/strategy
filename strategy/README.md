# strategy · 전략 프레임워크 추천 스킬

자연어로 비즈니스 상황을 말하면, 컨설팅 전략 프레임워크 70개 중 가장 맞는 **1순위 도구**와 보조 1~2개를 골라 적용 첫 단계까지 안내하는 Claude 스킬입니다.

## 무엇을 하나

- 입력: "신사업, 시장부터 보고 싶어요", "팀 동기부여가 잘 안 돼요" 같은 한 줄 상황.
- 출력: 1순위 프레임워크 + 보조 1~2개, 왜 그 도구인지, 적용 첫 단계, 한계와 대안.

설명이 아니라 "내 상황에 맞는 선택"이 핵심입니다. 단순 정의 검색("SWOT이 뭐야")이나 산출물(보고서·PPT) 작성은 다루지 않습니다.

## 구성

```
strategy/
├── SKILL.md                 # 스킬 본문 (동작 원칙·추천 절차·매핑 요약)
└── references/
    ├── decision-tree.md     # 상황 → 1순위 매핑 (분기 A~F·보조표·키워드 사전)
    └── frameworks.md        # 70개 전수 인벤토리 (한 줄 정의·언제·관련 도구)
```

본문은 자주 쓰는 매핑만 요약하고, 전체 인벤토리와 결정 트리는 `references/`가 단일 출처입니다. 모든 `#N`은 데이터(`../data/frameworks.js`)·갤러리 카드 번호와 정확히 일치합니다.

## 설치 (Claude Code)

스킬 폴더를 `~/.claude/skills/`에 링크합니다(저장소 루트에서 실행).

```bash
ln -s "$(pwd)/strategy" ~/.claude/skills/strategy
```

이후 `/strategy` 또는 "어떤 프레임워크 써야 해" 같은 표현으로 발동합니다.

## 사용 예

> "재고가 자꾸 쌓이고 리드타임이 길어요. 뭘 봐야 하죠?"

1순위 **가치 흐름 지도(VSM, #57)**, 보조 **린 7대 낭비(#56)·제약 이론(#61)**, 적용 첫 단계와 한계까지 한 번에 제시합니다.
